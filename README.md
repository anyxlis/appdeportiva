# BELAND HOUSE — Angular + Bootstrap

Primera vez:   npm install
Abrir la app:  npm start          → http://localhost:4200
  Tienda:            http://localhost:4200/#/
  Tienda de pruebas: http://localhost:4200/#/?pruebas
  Panel admin:       http://localhost:4200/#/admin
Publicar:      npm run build      → carpeta dist/beland-house/browser

Configuración del negocio y de Supabase: src/app/core/config.ts
La versión anterior (HTML/JS) quedó en la carpeta legacy/.
